# ArrowShop – MERN E-commerce Platform

ArrowShop is a full-stack e-commerce application built using the MERN stack.
The project demonstrates end-to-end implementation of a modern online store,
including authentication, product management, cart workflows, and order handling.

This project was originally developed as part of a structured MERN learning
program and later refined to follow **production-style architecture and patterns**.

---

## Tech Stack

**Frontend**
- React
- Redux & Redux Thunk
- React Router
- Bootstrap 5

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

---

## Key Features

- User authentication and authorization
- Product listing and detail pages
- Shopping cart and checkout flow
- State management using Redux
- RESTful API integration
- Modular frontend and backend separation

---

## Architecture Notes

- Frontend and backend are separated for clarity and scalability
- Redux is used to manage global application state
- APIs follow REST conventions
- Designed to reflect real-world e-commerce workflows
